# 长沙第三代试管费用大概多少？

## 费用流程及试管移植过程

 1. 前期检查：包括卵巢功能检查、染色体检查、激素水平检查等，花费约5000元左右。

 3. 精子处理：采集丈夫或捐赠者的精子进行筛选和处理，费用约为3000元左右。

 4. 胚胎植入：将经过体外受精的胚胎移植到女性子宫内，费用约为8000元左右。

 5. 基因筛查：对胚胎进行基因检测，筛选健康胚胎，费用约为1万元左右。

 6. 术后检查和保养：包括药物治疗、监测卵巢功能等，费用约为5000元左右。
