# 试管婴儿|为什么我取的卵子这么少她们能取那么多？

> 更新时间：2026-09-11 (UTC+8)

最近一段时间很多进周的准妈妈在我院进行取卵手术，取卵后有不少准妈妈在线上咨询小玛丽：“**为什么我取的卵子数量这么少？她们能取得这么多卵子？**”“**是不是促排方案的不同引起的结果？**”其实，有很多准妈妈都有这样的疑惑，为了让各位准妈妈清楚明白这其中的道理，今天小玛丽就和各位准妈妈说说为什么“**你取卵数量这么少而她们能取那么多？**”
**窦卵泡存量决定准妈妈取到的卵子数量**
准妈妈从出生的那一刻开始就已经注定了她所拥有的卵子数目，一般准妈妈的一生会排出成熟的卵子有400-500个，这些成熟的卵子是在众多窦卵泡数中唯一发育起来的优势卵泡，其余未发育的窦卵泡就会成为闭锁卵泡进而凋亡。促排卵的目的是通过外界给予这些未发育的窦卵泡充足的营养，使其发育成为优势卵泡并通过去取卵手术获取，从而增加准妈妈配出优质胚胎的机会。

**整个促排取卵过程可以看出，真正决定准妈妈能取到多少卵子数量的是准妈妈的窦卵泡存量！**如果准妈妈窦卵泡数存量已经比较稀少，无论多厉害的生殖主治医生都无法使得准妈妈获取到更多的卵子。
**准妈妈的年龄影响窦卵泡存量**
一般影响准妈妈窦卵泡数量与质量的因素有这两个：年龄、卵巢早衰

**影响因素一：年龄**

年龄是影响准妈妈窦卵泡数量和质量最主要的原因，年龄越大，卵巢功能越差，促排取到的卵子数量和质量都会受影响，相应的胚胎质量也会下降，那么一次试管成功怀孕的几率也会随之下降。

这就是我们要这么苦口婆心劝各位备孕困难的准妈妈要尽早进行试管备孕的原因所在。因为很多准妈妈在自己出现备孕困难后，期望通过中医调理能自然怀上宝宝，这种方法并不是不可行，而是有很多准妈妈备孕困难的原因并非吃中药调理就得以解决的，反而因此而耽误了不少时间。当准妈妈发现中药调理无法使其怀孕决定进行试管备孕时，此时准妈妈身体状况大不如从前，一次试管成功怀孕的几率就会大大减小。

看似试管成功的几率是把握在生殖主治医生的手中，但其实有很大一部分成功率是掌握在准爸妈的手中的，越早进行试管备孕成功率越高。**即使准妈妈选择其他医院进行试管备孕，我们也希望准妈妈尽早进行****。**
**卵巢早衰影响窦卵泡存量**
**影响因素二：卵巢早衰**

现在很多年轻的女性都有熬夜的习惯，短期内可能感受不到熬夜对身体的伤害，从而更加肆无忌惮地熬夜。等到自己备孕困难检查身体发现AMH值小于1ng/ml，卵巢功能严重衰退！在临床上我们经常遇到30岁左右的准妈妈卵巢早衰，30岁的准妈妈卵巢功能相当于40岁以上卵巢功能。卵巢如果提前衰老，那么相应的窦卵泡数量和质量也会相应变少和变差。

**对于每一位在未来需要孕育的年轻女性来说，最好不要熬夜，熬夜对卵巢功能损伤尤其重，而且只是无论日后花多少钱都不可扭转的局面**。

总言之，每一位准妈妈因为不同的身体情况致使备孕困难后进行试管备孕，**在试管备孕中千万不要与其他准妈妈比较，越比较越会影响准妈妈的状态。最应该要做的事是积极配合医生的治疗，保持情绪的平稳，这样才更加有利于准妈妈的试管备孕**。同时，如果你对试管备孕你还有其他疑惑，**拨打****0898-66517788或加文末小玛丽的微信，我们将全力为你解答****。**我们就是这样一群人，用专业的技术，敬业的态度，职业的修养，高成功率的成绩，全身心助你成功怀孕！
